Mi trabajo en proyectos

Problemas reales, las decisiones que tomé y lo que aprendí. Tocá cada tarjeta para leer más.

Caso 01 · ITTI · 2024 — hoy
  • .NET 9
  • Clean Architecture
  • PostgreSQL

¿Cómo se diseña un sistema de crédito desde cero?

Me tocó diseñar el nuevo sistema de originación de crédito. Lo armé por capas (API, aplicación, dominio e infraestructura) para que las reglas del negocio vivan separadas de la base de datos y se puedan probar sin miedo.

Decisiones: Entity Framework Core Code-First, patrones Repository y Unit of Work, y PostgreSQL.

Caso 02 · ITTI · 2024
  • .NET Core
  • Serilog
  • Legacy

¿Qué hacés cuando un sistema crítico calcula mal?

Migré el sistema PCA de originación de crédito a .NET Core y corregí bugs críticos de lógica financiera, mejorando la integridad de los datos.

Lo que aprendí: sin buenos logs no hay diagnóstico. Sumé logging estructurado con Serilog y el equipo empezó a encontrar errores mucho más rápido.

Caso 03 · Bepsa · 2022 — 2024
  • Node.js
  • Microservicios
  • DB2

¿Cómo hacés que tres bases de datos convivan en paz?

Diseñé APIs REST en Node.js y Express dentro de una arquitectura de microservicios de alto volumen, integrando PostgreSQL, MongoDB y DB2.

La clave: migraciones versionadas con Knex y Liquibase, para que desarrollo y producción nunca se desincronicen. También modernicé módulos legacy en C#.

Caso 04 · Roshka · 2016 — 2019
  • Frontend
  • Banca digital
  • Alta disponibilidad

¿Cómo es trabajar en un sistema que no se puede caer?

Desarrollé y mantuve el frontend del homebanking de Banco Itaú Paraguay, un sistema transaccional que tenía que estar disponible todo el tiempo. También el sistema de gestión financiera de CAJUBI.

Lo que aprendí: cuando miles de personas dependen de un sistema, cada cambio que pasa a producción se cuida al detalle.
